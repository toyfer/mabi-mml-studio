API リファレンス

変換エンジンは依存関係のないES Modulesです。ブラウザ、Node.js、Cloudflare Workersのどこでも同じ結果になります。

構成：GitHub Pagesは静的ホスティングのため、サーバー側APIは置けません。そこで①JS API（Pages上でそのまま動く）と、②REST API（同梱のCloudflare Workerをデプロイ）の2つを用意しています。

1. JavaScript API

サイト上の src/api.js を読み込むだけで使えます。ビルド不要、外部依存なし。

import { convertMidi } from 'https://your-name.github.io/mabi-mml/src/api.js';

const buffer = await file.arrayBuffer();
const result = convertMidi(buffer, {
  parts: 3,
  instrument: 'lute',
  grid: 20,
  tieMode: 'melody',
});

console.log(result.parts[0].mml);
console.log(result.combined);   // MML@...,...,...;

ブラウザでは window.MabiMML も生えます。

const result = window.MabiMML.convertMidi(bytes, { parts: 6 });

1.2 トラックを手動で割り当てる

trackMap を使うと、MIDIのトラック番号を直接パートへ割り当てられます。キーがトラック番号（0始まり）、値がパート番号（0＝メロディ、1〜5＝和音1〜5、-1＝除外）です。指定しなかったトラックは空きパートへ自動配分されます。

convertMidi(buffer, {
  parts: 3,
  assignment: 'manual',
  trackMap: { 0: 0, 1: 1, 2: 2, 3: -1 }, // トラック3は除外
});

結果の tracks には、各トラックの名前・音符数・平均音高・最大同時発音数・割当先パートが入ります。サイトの「パート割当 → 手動（トラックを指定）」はこの仕組みを使っています。

1.3 トラックを声部に分割する

splitMap は1つのトラックを複数の単音トラックへ分ける指定です。値が2〜4のトラックは、同じタイミングで鳴っている音を高い順に別々の声へ割り振り、トラック名 [1] のような別トラックとして扱います。ピアノの右手・左手・内声を別パートにしたいときに使います。声が埋まっている区間では直前の音を切って場所を明け、切れない場合はその音を間引きます（stats.dropped に加算）。

convertMidi(buffer, {
  parts: 6,
  splitMap: { 2: 3 },              // トラック2を3声に分割
  assignment: 'manual',
  trackMap: { 4: 0, 5: 1, 6: 2 },  // 分割後のIDに割当
});

分割後の声は元のトラックより後ろの番号が振られます。どのIDがどの声かは、結果の tracks にある src（元トラック番号）・voice（何声目か）・count（分割数）で判定してください。元の和音が3音までなら、4声を指定しても3声しか現れません。

2. REST API（Cloudflare Worker）

同梱の worker/index.js を wrangler deploy すると、次のエンドポイントが使えます。

メソッドパス説明
GET/v1/spec制限値・楽器・既定オプションを返す
POST/v1/convertMIDIをMMLへ変換

2.1 multipart

curl -X POST https://mabi-mml.example.workers.dev/v1/convert \
  -F "midi=@song.mid" \
  -F "parts=6" \
  -F "tieMode=melody" \
  -F "charLimit=2400"

2.2 JSON（base64）

curl -X POST https://mabi-mml.example.workers.dev/v1/convert \
  -H "content-type: application/json" \
  -d '{"midi":"TVRoZA...","options":{"parts":3,"grid":20}}'

2.3 バイナリ直送

curl -X POST https://mabi-mml.example.workers.dev/v1/convert \
  -H "content-type: application/octet-stream" \
  --data-binary @song.mid

2.4 デプロイ

npm i -g wrangler
wrangler deploy worker/index.js --name mabi-mml-api --compatibility-date 2026-01-01

Workerはsrc/coreをそのままimportします。wranglerがバンドルするため、追加の設定は不要です。CORSは全オリジン許可。OPTIONSにも応答します。
